# TrendForge sample video

`trendforge-free-demo.mp4` is generated by GitHub Actions using only open-source local tools:

- Python and Pillow for original vertical motion-graphic scene cards
- FFmpeg for H.264/AAC MP4 encoding and timed captions
- eSpeak NG for offline synthetic narration

This sample makes **no Groq API calls, YouTube API calls, OAuth requests, or paid API calls**. Its narration and metadata are illustrative, not live trend research. The production pipeline uses Groq for script generation and the YouTube Data API for source discovery; those services require your own free-tier credentials.
